## Introduction
 This project is a simple e-commerce shopping cart app built with React. State is managed using
React Context API. Navigation between pages is handled with React Router.




## Installation
 1- Clone the repository  
  ```bash
  git clone https://github.com/ParvinBahram/mini-shop-react.git
  ```

 2- Be sure Node.js is installed on your system.


 3- Navigate to the project directory :
```bash 
 cd mini-shop-react
```

 4- In terminal, install dependency to create node modules folder:
  ```bash
    npm i
```

### 5- Run the project
```bash
npm run dev 
```
### 6-  Open your browser at the address shown in the terminal.




## Features
-  Browse all products in a responsive grid

-  View detailed info for each product

-  Add products to the shopping cart

-  Increase or decrease item quantity

-  Remove items from the cart

-  Clear the entire cart at once

-  See total price calculated live

-  Fully responsive on all devices

-  NotFound Page

-  Styled with Tailwind CSS






## Tech Stack
- React
- React Router
- Context API
- Tailwind CSS
- Vite
